## Design Context

### Users
pi-frame serves developers who use the `pi` coding agent for sustained, repository-based work. They need to move quickly between agent conversations, workspaces, worktrees, diffs, terminals, models, skills, and extensions without losing session context.

### Brand Personality
Quiet, technical, and dependable. The interface should feel like a focused native development tool: information-dense, precise, and calm rather than decorative or promotional.

### Aesthetic Direction
Preserve the existing Codex-style desktop language: compact typography, restrained surfaces, clear state signals, strong keyboard ergonomics, and polished light and dark themes. Localization should fit the established layout instead of redesigning it. Simplified Chinese copy should read naturally while product names, code, paths, commands, and runtime-owned content remain unchanged.

### Design Principles
- Keep conversations, tool activity, and session correctness visually primary.
- Prefer compact, familiar desktop controls and predictable navigation.
- Use semantic color only for status, selection, and feedback.
- Make English and Simplified Chinese equally complete, accessible, and resistant to overflow.
- Translate developer concepts consistently: thread as "对话", session as "会话", workspace as "工作区", worktree as "工作树", provider as "模型提供商", and skill as "技能".
